----------------------------------

npm install 
2. CHUẨN BỊ CÁC FILE DỮ LIỆU
---------------------------
  * Mode 1: Chạy đăng ký mới (Reg)
  * Mode 2: Chạy đào (Mining) cho acc đã có trong profiles.json

- proxy.txt: Danh sách proxy (mỗi dòng 1 proxy).
  Định dạng: ip:port hoặc user:pass@ip:port

- ref.txt: Danh sách mã mời (Referral Code), mỗi dòng 1 mã.

- User_agents.txt: Danh sách User-Agent trình duyệt, mỗi dòng 1 UA.

Bước 3: Tool sẽ tự động kiểm tra bản quyền và bắt đầu chạy.
